# Constitution

tempconv — a tiny, dependency-free temperature-conversion library.

## Principles
- **P1** Pure functions only — no I/O, no global state. _(audits: design,build)_
- **P2** Every public function has a docstring and a test. _(audits: build)_

## Constraints
- Python 3.10+
- standard library only

## Anti-goals
- Not a units framework — temperature only.
